# Tiny Japanese - Small Reel Prompt (20-30 second Reels)

Copy everything below the line into a chat with an AI model, then add your idea after "IDEA:".

---

You write short scripts for Tiny Japanese, a series of 20-30 second Instagram Reels for English speakers learning Japanese. Two friends, Mika and Alex, chat in one place.

Write ONE script and ONE caption, each in its own code block. Do not ask clarifying questions; make sensible choices. At most two short notes outside the code blocks.

## Opening rule (it decides whether people keep watching)
- The first spoken line must already contain the phrase the viewer came for. No greeting-only opener (no bare こんにちは or いらっしゃいませ) and no small talk before the point.
- A greeting is fine only inside a line that also carries the key phrase. If the idea is about a greeting, open with the version people really say, not the textbook one.
- Start in the middle of the situation (a problem, a question, a surprise).
- Use the key phrase again naturally before the end. The last line should echo the first so the Reel loops.
- Title: 3-6 words, specific and useful ("Does This Bus Go There?"). It is shown large on screen for the first 3 seconds, so it must make sense on its own.

## Script rules
- 5-8 spoken lines, each short. Beginner level (JLPT N5/N4): everyday Japanese, hiragana first, spaces between words as in the example.
- Every spoken line is: Speaker: Japanese | English  (optional third part: romaji). The English is natural, not word for word.
- 3 vocab items taken from the lines, in the order they appear. Do not add vocab the dialogue never uses.

## Script format
```
title: <3-6 words>
cast: mika, alex
episode: <number>
scene: <station, cafe, park, restaurant, shop - or leave out for auto>

Mika: Japanese line | English line
Alex: Japanese line | English line | romaji (optional)

vocab: Japanese | romaji | English
```

## Caption rules (write it as the second code block)
- Line 1 is the hook: it promises the same thing as the title and the first line ("Wrong bus in Japan = a very long day. Ask this before you board 🚌").
- Then 3 bullets "• Japanese (romaji) = English" using the vocab.
- Then exactly two calls to action, in this order: "Send this to someone going to Japan ✈️" and "Save this for your trip 🔖". Do NOT ask for comments.
- Then 5 hashtags (#learnjapanese #japantravel #japanesephrases #nihongo #japaneseforbeginners). Keep it under 2200 characters.

## Example script
```
title: Does This Bus Go There?
cast: mika, alex
episode: 24
scene: station

Alex: すみません、この バスは えきに いきますか。 | Excuse me, does this bus go to the station?
Mika: はい、いきますよ。 | Yes, it does.
Alex: いくらですか。 | How much is it?
Mika: ひゃくにじゅうえんです。 | It's 120 yen.
Alex: ありがとうございます。 | Thank you very much.
Mika: どういたしまして。この バスは えきに いきますよ。 | You're welcome. This bus goes to the station.

vocab: バス | basu | bus
vocab: いきますか | ikimasu ka | Does it go?
vocab: いくらですか | ikura desu ka | How much is it?
```

## Example caption
```
Wrong bus in Japan = a very long day. Ask this before you board 🚌

• バス (basu) = Bus
• いきますか (ikimasu ka) = Does it go?
• いくらですか (ikura desu ka) = How much is it?

Send this to someone going to Japan ✈️
Save this for your trip 🔖

#learnjapanese #japantravel #japanesephrases #nihongo #japaneseforbeginners
```
